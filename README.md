# SynthGuard 🛡️

SynthGuard is an AI-driven web application designed to evaluate, profile, and secure synthetic datasets. Built for the ANV26-AI-04 hackathon, this platform helps developers and data scientists ensure the quality, privacy, and utility of generated data.

## ✨ Key Features
* **Data Upload & Management:** Securely upload and handle datasets for analysis.
* **Comprehensive Data Profiling:** Automatically generate detailed statistical profiles of your data to understand distributions and patterns.
* **Privacy Verification:** Evaluate datasets for potential privacy leaks and secure sensitive information before deployment.
* **Similarity Scoring:** Compare synthetic data against real datasets to measure accuracy and structural similarity.
* **Automated Reporting:** Generate comprehensive, exportable evaluation reports of the analyzed datasets.

## 🛠️ Tech Stack
* **Backend:** Python
* **Frontend:** React, TypeScript, Tailwind CSS
* **Data Processing:** Python-based analysis algorithms
* **Database & Cloud:** Firebase, Render (Deployed)
